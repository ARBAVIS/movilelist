🎬 React Movie List App
This is a simple React.js application built using Vite that fetches and displays a list of movies from a public API:
👉 https://dummyapi.online/api/movies

🛠️ Features
Fetches movie data from a public REST API

Displays:

Movie title

Release year

Rating

Poster image

Responsive card layout

Built with functional components and React Hooks

📦 Tech Stack
React.js

Vite

JavaScript (ES6+)

CSS (inline or your preferred framework)
